# 《阴契：回水名册》首版互动剧情稿

版本：内容稿 V0.1；供《阴契》Godot 原型接入。只对应“村口 → 河桥”两处，不替代完整纸新娘主案。

## 一、叙事与实现边界

陈默是玩家视角人物，台词短、务实、遇事先找退路；不主动向玩家讲世界观。林晚秋只通过物证与录音显形，本章不让她以完整鬼影现身。苏青青不在场，只留下一段录音。环境中的“纸船送名”及“水中呼名不可应”都是归魂村的虚构设定，不作为现实民俗知识呈现。

全篇只有一个核心推理：从录音、姓名、脚印与纸船判断应送走林晚秋的名字，并在河中呼唤陈默时保持沉默。玩家不需要战斗、跳跃、自由镜头、背包或手机权限。重要线索提供文字替代，失败后回到桥头、线索不丢失，可直接重试。

## 二、进入游戏

【标题】《阴契：回水名册》

【按钮】开始 / 重新开始 / 设置

【设置提示】本章包含低频惊吓、短暂画面闪暗与追逐音效。闪光可关闭，声音可调低；全部声音线索均有文字稿。

【开场字幕】
23:47。陈默接下最后一单，送一盏白灯到归魂村河桥。
备注只有一句：过了子时，收货人若在水里喊你，不要答应。

【陈默】“送灯到桥边，签收人不留名。现在的单子，备注倒挺像遗书。”

## 三、场景 A：村口

### 镜头与氛围

固定镜头，雾、断裂界碑、熄火的电瓶车。无突发跳吓。玩家可左/右切换视角；交互物上出现简短名称，点开后给一段描述和线索卡。

### 入口台词

【陈默】“车没电，导航也没信号。先找条能出去的路。”

【系统目标】找到通往河桥的路。

### 交互 A1：断裂界碑

【调查】碑面缺了一角，断口还泛着湿亮的暗红。碑后土路有两道凌乱拖痕，向村外延伸几米后突然消失。

【陈默】“有人走出去过……还是被拖出去的？”

【获得线索】新鲜断口与拖痕。

### 交互 A2：村民公约

【调查】旧木牌上写着村规。第三条被红漆涂掉，下面露出几笔褪色小字：

“子时过桥，闻水呼名，不可应。”

边角另有一行更小的字：“纸船顺水，不载活人名。”

【陈默】“写给外人的规矩，通常不是为了让外人好过。”

【获得线索】被涂掉的第三条。

### 交互 A3：备用麦克风

【调查】一支旧麦克风塞在电瓶车篮底，按下播放键后，先传出风噪，再传来断续的女人声音。

【录音·苏青青】“……桥上……别喊名字……船要顺着水……晚秋，你听见没有？”

随后是急促喘息、重物落水声，录音中断。

【陈默】“晚秋。至少这不是谁喝醉了在唱歌。”

【获得线索】落水声录音。

### 前往河桥

首次点击出口：

【陈默】“白灯在我手上。要签收，就得有人出来。”

【系统提示】沿雾路前往河桥？【前往 / 再检查村口】

## 四、场景 B：河桥

### 镜头与氛围

固定镜头切换：桥头灯位 / 桥栏 / 桥面。水流、雾和灯光能轻微变化，但首次进入不触发追逐。白灯落在桥头，灯芯仍未点燃。

### 首次进入台词

【陈默】“灯放这儿。人呢？”

【环境音】水下传来很轻的拍击声，随后一声类似陈默的呼唤。

【陈默】“我还没签收。”

### 交互 B1：浸水白布

【调查】一截白布缠在桥栏下方，沾着油腻的香味，边缘被水泡得发灰。布角缝着两个字母：L.W.

【陈默】“这不是用来擦灯的。”

【获得线索】带字母的浸水白布。

### 交互 B2：草鞋与脚印

【调查】桥面留着一双草鞋。脚印从村道走到桥边，没有折返的痕迹；最后两枚鞋印边缘被水冲散。

【陈默】“她自己走到这儿，然后没能走回去。”

【获得线索】止于桥边的脚印。

### 交互 B3：学生证

【调查】桥缝里卡着一张发潮的学生证。照片上的年轻女人望着镜头，证件姓名是林晚秋，美术系。

【陈默】“林晚秋。L.W. 对上了。”

【获得线索】林晚秋的学生证。

### 可选回顾交互：线索板

【标题】你目前知道的

- 公约提示：子时过桥，水中呼名不可回应。
- 录音提到“晚秋”和顺水而行的船。
- 白布字母与学生证姓名相符。
- 草鞋印停在桥边，没有返回。

【陈默】“不是让我替谁找路，是让我别把自己的名字交出去。”

## 五、核心谜题：纸船名牌

### 显示条件

五类关键线索齐备后，三只纸船名牌清晰可读并开放放船判断；此前可以看到船影，但名牌不可辨、不能执行放船。玩家可随时继续调查，不因调查顺序软锁。

### 纸船描述

1. “陈默”：纸面被新墨写过，墨迹仍湿。
2. “林晚秋”：名字被水洇开一半；船头朝向下游。
3. 空白名牌：没有墨迹，船底压着一颗湿透的纽扣。

【交互提示】检查 / 将纸船放入水中 / 暂不触碰

### 推理反馈

玩家选“林晚秋”并选择“顺水放下”时进入正确分支；选“陈默”、空白船或逆水放船均进入错误分支。若系统当前无法表达方向选项，则把船头方向画面做清楚，玩家只选船；正确船头方向由交互自动处理，并保留反馈文案。

### 正确分支文本

【动作】陈默把写着林晚秋名字的纸船放在水面。纸船先在灯影里打了个转，随后顺流漂远。

【陈默】“名字还给你。剩下的事，我不替他们做主。”

【环境】河水拍岸三次。第三次之后，所有声音突然停止。

【提示】桥下传来熟悉的男声：“陈默——”

【选择】回应 / 不回答，退到灯下

正确选择：

【陈默】“名单上没有我。”

【动作】他熄掉手电，退回白灯照得到的地方，没有朝水面看。

【环境】水声恢复，雾从桥面散开；手机重新收到信号。

【获得状态】本夜异象暂时平息。

### 错误分支文本

若放下错误纸船、逆水放船或回应呼唤：

【环境】灯光一暗，桥面传来连续三声湿脚步。水中倒影抬起头，岸上的陈默没有动。

【陈默】“不是我。那上面不是我的名字。”

【系统提示】你听从了错误的呼唤；线索仍保留，可以重新判断。 【重新尝试 / 回标题】

【重置】短暂追逐结束后返回河桥灯位；谜题选择重置，已收集线索保留。失败不扣永久资源、不删档、不要求从头重复村口调查。

若玩家尝试重复调查已调查物件，显示不同但简短的重复检查文字，不重复发放线索。

## 六、结尾

### 通关画面

【动作】陈默走回村口。雾薄了，电瓶车仍然无法启动，但手机恢复一格信号。

【手机通知】跑腿订单更新：收货点改为“归魂村老宅”。备注栏空白。

【陈默】“这单先不接。”

【结案文字】《回水名册》：林晚秋的名字已确认；河桥呼唤暂时停止。归魂村的其他异常仍未查明。

【按钮】再玩一次 / 回标题

### 重玩要求

从标题再次进入必须清空本章线索、风险与纸船状态；不能沿用上次结果，也不能让失败次数、关闭设置或音量设置被无故重置。

## 七、内容验收清单

- 开场在十秒内交代时间、跑腿任务与危险提示。
- 村口三个线索都能由玩家主动调查，前往河桥不依赖难以发现的像素点击。
- 玩家可以从姓名、字母、录音、脚印推断林晚秋与河桥有关；核心规则有可读证据。
- 错误选择有清晰因果与可恢复反馈，正确答案不依赖随机猜测。
- 音频线索在静音时仍能靠字幕理解；追逐/闪暗能关闭或降低。
- 本章解决“名字该送给谁、玩家是否回应水中呼名”，不声称解决林晚秋全案。
- 不出现对《纸嫁衣》角色、独特对白、特定谜题流程或画面构图的复制。
- 所有故事内虚构禁忌标注为归魂村设定，不伪装现实民俗事实。


## 八、与最终内容规格的实现对齐

1. **谜题开放条件**：收集五类核心线索（录音、村规、白布、脚印、学生证）后开放纸船放船判断。提前发现船影不等于能提前答题。
2. **纸船答案与河中呼名**：三只名牌为“陈默”“林晚秋”“空白”；将林晚秋号顺水放下后，河中再呼唤“陈默”，必须选择保持沉默/退到灯下才能通关。
3. **失败与恢复**：错船、逆流放船或回应呼唤都会回到河桥灯位，已获线索保留；每次新游戏最多出现一次短追逐/惊吓。累计两次错误后显示可关闭的明确提示；错误不扣永久资源、不删档、不软锁。
4. **章内边界**：林晚秋不以完整鬼影现身；没有“给纸人点眼睛”的可交互项，也不进入老宅、戏台或祠堂。本章只暂时平息河桥呼唤，不宣称解决林晚秋全案。
5. **虚构规则标识**：“水中呼名不可应”与“纸船送名”仅为归魂村/本作品虚构设定，不作为现实民俗说明。所有听觉信息均同步提供文字稿，不请求麦克风、陀螺仪权限。
